SamRegionHop region (CSC) changer for Samsung phones

Unofficial · not affiliated with Samsung. Run the steps in order; steps 1–4 change nothing.

  1. 1Read phone read-only

    Model, firmware, current region, and whether a change wipes the phone. Needs USB debugging on.

  2. 2Check updates read-only

    Asks Samsung which regions can update your current build.

  3. 3Test modem read-only

    In Developer options turn on Stay awake and, if it's listed, 3GPP AT commands. Then dial *#0*# and leave that screen open.

  4. 4Dry run read-only

    Every check of a real change, then stops. Keep *#0*# open.

  5. 5Change region

    May factory reset the phone, so back up first. Unlocks after a passing dry run for this region.

ReadyPlug in the phone and start with step 1.
Final confirmation
Type the region code to change it. Anything else cancels and changes nothing.
